# Security policy

## Supported version

Only the current public release is supported.

## Report a vulnerability

Please use the repository’s private **Security → Report a vulnerability**
flow. Do not include secrets, credentials, patient information, or other
sensitive personal data in a public issue.

PalDawn v0.1.0 is a static client-side site with no account, backend, analytics
SDK, or patient-data path. Reports about medical or anatomical accuracy belong
in the medical-accuracy issue template and must not contain private health
information.
