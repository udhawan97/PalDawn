# Atlas Study Desk

Atlas Study Desk collects the public app's existing local study and evidence
tools into one keyboard-accessible surface. It adds navigation and organization;
it does not add medical claims, assessment, diagnosis, or treatment guidance.

## Study view

- Counts active, saved, open, studied, and noted records.
- Filters saved, open, studied, noted, and unavailable records without changing
  them.
- Searches condition names, authored step labels, phases, and private notes
  locally in the browser.
- Opens an exact current step or continues the next saved step without a personal
  study mark.
- Downloads the complete source-linked Atlas study as Markdown. Private notes
  remain excluded until the learner opts in.
- Prints the currently filtered study list. Private notes remain excluded from
  print until the learner uses the same explicit opt-in. Removed catalog targets remain
  visible and continue to participate in complete export and backup recovery.

## Body-system view

The system index is generated from each existing step's explicit `bodyParts`
IDs. A result therefore means only that the authored mechanism step names that
structure. PalDawn does not infer a new disease association, and the interface
states that limit before the learner opens a result.

## Evidence view

The evidence library aggregates the existing source ledgers for the ten current
previews. Source records retain their exact disease and step indexes. Sources
with no linked mechanism step remain labeled as ranking context rather than
being promoted to step evidence. Named qualified review remains pending.

## Verification boundary

Deterministic checks cover local-study filters and counts, unavailable-record
recovery, explicit system membership, evidence totals, and ranking-context
separation. Browser checks cover local note search, complete export, system
arrival, evidence lookup, focus containment, narrow layout, Chromium, and
WebKit. The feature does not require WebGL and does not change local-data schema
version 3.
