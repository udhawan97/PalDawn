## Product-positioning boundary from the bounded GitHub recon

- The inspected repositories demonstrate that organ exploration, hotspots/labels, isolate/layer controls, quizzes, multilingual terminology, fly-to cameras, and volume/atlas overlays already exist; those capabilities alone are weak differentiation. **(verified: viewer evidence in section 1)**
- Four named repository searches—[`"heart attack" threejs`](https://github.com/search?q=%22heart+attack%22+threejs&type=repositories), [`pathophysiology threejs`](https://github.com/search?q=pathophysiology+threejs&type=repositories), [`"disease journey" anatomy 3D`](https://github.com/search?q=%22disease+journey%22+anatomy+3D&type=repositories), and [`"myocardial infarction" WebGL`](https://github.com/search?q=%22myocardial+infarction%22+WebGL&type=repositories)—returned no repository result at capture time. This bounded result is not proof that no competing product exists. **(verified: linked searches, captured 2026-08-16)**
- Product recommendation: position Antaryaan as an **evidence-linked causal voyage engine**—a spatial, time-based explanation of disease mechanism with synchronized lay/clinical narration and claim-level sources—not as another 3D anatomy atlas. “Fly through a heart attack from plaque rupture to tissue death” is the narrow launch wedge. **(verified as an engineering/product synthesis; uniqueness is not asserted as a market fact)**

### NCBI Bookshelf and content-license boundary

- No worthwhile current Bookshelf-specific JS/TS harvester surfaced: the named GitHub repository search [`NCBI Bookshelf TypeScript EUtils`](https://github.com/search?q=NCBI+Bookshelf+TypeScript+EUtils&type=repositories) returned no repository result at capture time. Add `db=books` to the same NCBI client: curated ID/query allowlist → ESearch only for discovery → ESummary metadata → stable `https://www.ncbi.nlm.nih.gov/books/{NBK…}/` link. Store stable ID, canonical URL, retrieval time, source, license class, and content hash. **(verified: the linked search returned zero results at capture time; [live Books EInfo](https://eutils.ncbi.nlm.nih.gov/entrez/eutils/einfo.fcgi?db=books&retmode=json), [NCBI E-utilities documentation](https://www.ncbi.nlm.nih.gov/books/NBK25497/))**
- NCBI permits at most three E-utility requests per second without an API key and asks automated clients to register `tool` and developer `email`; schedule large jobs off-peak. **(verified: [NCBI policy](https://www.ncbi.nlm.nih.gov/books/NBK25497/))**
- Do not mirror arbitrary Bookshelf text: copyright remains title-specific and free access does not imply reuse permission. Current StatPearls content is CC BY-NC-ND 4.0, so keep citation metadata/canonical links and write independent multi-source summaries; do not adapt StatPearls prose into the CC BY-SA content pack. **(verified: [Bookshelf FAQ](https://www.ncbi.nlm.nih.gov/books/NBK45610/), [Bookshelf overview](https://www.ncbi.nlm.nih.gov/books/about/overview/), [StatPearls record/license](https://www.ncbi.nlm.nih.gov/books/NBK430685/))**
- MedlinePlus health-topic summaries are public domain and reusable with the requested credit, but A.D.A.M. encyclopedia material, ASHP drug monographs, and many images are protected. Required content credit: `Source: MedlinePlus, National Library of Medicine.` **(verified: [MedlinePlus content-use rules](https://medlineplus.gov/about/using/usingcontent/), [Web Service docs](https://medlineplus.gov/about/developers/webservices/))**
