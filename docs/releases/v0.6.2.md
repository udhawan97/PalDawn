# PalDawn v0.6.2 — Connected Scene Engineering

**Proposed source-release notes.** Publication is established by the matching
GitHub Release after the exact main commit passes CI and GitHub Pages.

This release packages the integrated P0–P3 engineering work. The public
Mechanism Lens retains its existing content, storage schemas and dependencies.
The synthetic graphics studies remain local and excluded from the public app.

## Added

- A connected cutaway Y junction with one parent opening and two exits, stable
  seeded identities and branch ownership, and deterministic GPU flow in
  arbitrary teaching units.
- A shared 12-second scene contract for Overview, Junction and Inside shots.
  Seeking and inspection return resolve the same camera, caption and flow time;
  reduced motion keeps still-frame and text routes available.
- Explicit delayed-scene failure, retry and stale-response checks that preserve
  the last readable frame and require explicit playback after recovery.

- A separate immutable runtime manifest and bounded loader, demonstrated by six
  original mathematical mesh fixtures. Digest, compatibility, stream limits,
  stale-request rejection and resource disposal are checked before activation.
- A scene-pack lab with retained-scene recovery, explicit retry, detail tiers
  and text continuation after corruption, timeout or WebGL loss.
- A seven-shot heart/chest review dossier listing every existing mesh part,
  source and rights scope, available views and missing geometry.

## Distribution and review limits

GitHub provides source ZIP/tar archives after the exact-commit publication gate.
There is no native installer, signing or notarization. Browser installation is
optional and browser-dependent; source/CI checks do not prove installed-PWA use.

The junction is an original synthetic engineering fixture, not reviewed anatomy
or a validated physiological simulation. Anatomy Lab remains a separately
prepared candidate. No new medical lesson, diagnosis, treatment guidance,
qualified review, native Safari animation/pixel acceptance, VoiceOver, physical
touch or measured target-performance result is claimed. P3 engineering is development-only. P4–P5, production pack adoption and
reference-pack publication remain future gates. The 512 KiB tracked payload
ceiling covers manifest, geometry and outstanding request reservations; it is
not a measured browser, allocator or GPU-driver memory limit.
