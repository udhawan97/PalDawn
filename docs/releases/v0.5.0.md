# PalDawn v0.5.0 — Study Navigation

## Added

- Atlas Study Desk with local progress counts, private-note search, saved/open/
  studied filters, next-open continuation, complete Markdown export, and a
  printable filtered view.
- System-first pathway discovery generated only from structures explicitly named
  by the existing authored steps.
- Searchable evidence library across all ten current previews, preserving exact
  source-to-step links and keeping ranking context separate.
- Stable exact-step links, Atlas saved steps, private notes, personal study
  marks, resume, pathway comparison, and transactional backup schema v3.

## Improved

- Anatomy Lab's local reading queue now has read/unread filters, completion
  counts, and next-unread continuation.
- Anatomy Lab restores the last selected source concept for each reference only
  after validating it against the loaded inventory. JSON backup schema v2 keeps
  importing schema-v1 backups.

## Documentation

- Synchronized README, getting-started, Study Continuity, Anatomy Lab, project
  plan, app architecture, changelog, diagnostics, and release metadata with the
  verified v0.5.0 behavior.

## Known Issues

- Anatomy Lab remains a separately prepared local candidate and is excluded from
  the public GitHub Pages build. Named qualified anatomy and clinical review is
  pending.
- Physical-mobile acceptance remains a manual follow-up. Native Safari print
  preview and the two-engine browser matrix passed. The public model
  remains conceptual, unreviewed, and not to scale.
