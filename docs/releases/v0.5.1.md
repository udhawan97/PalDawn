# PalDawn v0.5.1 — Recovery Integrity

## Fixed

- A First Light tab with a memory-only private note or checkpoint now keeps
  that work when another tab updates browser storage. The conflict remains
  visible so the learner can copy or export before deliberately reloading.
- Focused pathway reading now contains keyboard focus, handles Escape before
  the underlying Atlas, and returns focus to its opener.
- First Light transcripts, focused pathway study sheets and Atlas Study Desk
  results now print their authored content. Private notes remain excluded until
  the learner explicitly includes them.
- Anatomy Lab now refuses additions at its bounded structure and reading limits
  with truthful feedback instead of acknowledging data omitted from storage or
  backup.
- Unsaved Anatomy study work now survives same-tab navigation away from and
  back to the local candidate.

## Delivery

- GitHub Pages now runs the real service-worker browser lifecycle gate for the
  triggering commit before uploading the public artifact. The build job keeps
  read-only repository permission, and the privileged deploy job still only
  publishes the checked `app/dist` artifact.

## Boundaries

- This is a software recovery, accessibility and delivery release. It adds no
  medical or anatomical claims and supplies no qualified-human review.
- Anatomy Lab remains a separately prepared local candidate and is excluded
  from the public GitHub Pages build.
- Physical-mobile and native Safari service-worker migration remain separate
  manual acceptance surfaces.
