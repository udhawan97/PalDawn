# PalDawn v0.1.0 — First Light

Release date: 2026-08-20

First Light is PalDawn’s first public, end-to-end technical voyage. It proves
the route, camera, portal, corridor, analytic-flow, narration, accessibility,
governance, and static-publication systems on a deliberately synthetic model.

## What to try

1. Begin the voyage and follow all five stages.
2. Switch Guide ↔ Engineering narration without changing the scene.
3. Scrub or select a stage, then use Space and the arrow keys.
4. Open Settings and try reduced motion, high contrast, quality tiers, and
   runtime telemetry.
5. Open the transcript for the complete text route.

## Safety and provenance boundary

This is not a heart model and not a heart-attack lesson. The release contains
no anatomical asset, pathology, symptom explanation, patient data, diagnosis,
or treatment guidance. The model and route are authored procedurally in the
PalDawn codebase and are labeled synthetic in the entry screen, scene chrome,
mission panel, narration, transcript, README, and release notes.

The nine exact Z-Anatomy object targets plus the explicit aortic-root absence
record remain planned/pending/blocked. Their null adoption outputs are
intentional. See the [asset audit](../research/paldawn-heart-coronary-asset-audit.md).

## Verification

- App: type-check, production build, release-contract checks, and gzip budget.
- Supply chain: lockfile-based license inventory, 0 denied packages.
- Provenance: 23/23 live records pass and all invalid fixtures fail closed.
- Browser: desktop and mobile WebKit journeys, controls, panels, keyboard,
  reduced motion, and console checked locally.
- Performance: see [the v0.1.0 report](../performance/v0.1.0.md).

## Known limits

- This is a systems slice, not the later medically reviewed product journey.
- There is no audio narration; all narration is visible text with a complete
  transcript.
- The web app has install metadata but no offline service worker in v0.1.0.
- Auto quality is a simple heuristic. The user can select a tier directly.
- WebGPU, clinical content, imported 3D assets, full-body atlas/search,
  multilingual narration, and persistence are deferred.
