# PalDawn Foundation+

Status: post-v0.1.0 First Light mainline continuity wave. This is an
application-continuity wave, not a medical-content phase and not a release tag.

## Eight requested continuity features

1. Versioned, minimal, local-only persistence for comfort and display settings.
2. A bounded First Light resume prompt that never restores playback automatically.
3. Stable stage hashes plus user-triggered stage-link copying.
4. Copy, text-download, and print actions for the authored transcript.
5. A first-party offline service worker and explicit update-ready UI.
6. A keyboard-help panel with focus entry/return and a `?` shortcut.
7. User-triggered local diagnostic copy/download; no automatic upload.
8. Scene retry plus a scene-free text fallback that preserves journey state.

## Six additional high-confidence features

9. An always-available text voyage, independent of WebGL availability.
10. Standard, large, and largest SPD-caption settings.
11. Automatic pause when a playing voyage moves into the background, with an
    explicit resume action on return.
12. Local-data inspection/download plus a two-step reset action.
13. Fullscreen entry/exit when the browser exposes the Fullscreen API.
14. A completion summary with replay, transcript, and arrival-link actions.

## Boundary

Foundation+ adds no anatomy assets, medical or clinical teaching, pathology,
patient data, diagnostic logic, external analytics, backend, third-party runtime
dependency, WebGPU path, multilingual safety copy, quiz, or assessment. The
existing synthetic disclosure and emergency-services safety line remain release
contract requirements.

## Verification contract

- TypeScript app and Vite configuration type-check.
- Production build remains inside the existing gzip budget.
- First Light's five-stage, synthetic-only, no-medical-claim invariants pass.
- All fourteen Foundation+ feature contracts pass.
- Provenance validation and dependency-license inventory remain fail-closed.
- Browser acceptance covers keyboard, persistence, deep links, transcript and
  diagnostic exports, text voyage, recovery, responsive layouts, reduced motion,
  and same-origin offline reload at the production Pages base path. Static
  contracts cover the user-triggered service-worker update path.
